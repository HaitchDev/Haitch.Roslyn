# 13.1 New type declarations

## Goal
`SourceWriterExtensions.WriteNewTypeDeclaration(writer, NewTypeModel)` writes a non-partial type header with its modifiers, base list and type parameters, and opens its block.

## Touches
- `src/Haitch.Roslyn/Models/NewTypeModel.cs` (new)
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs`
- `tests/Haitch.Roslyn.Tests/Writing/NewTypeDeclarationTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes the full suite, including new `NewTypeDeclarationTests` asserting the full output for: `public sealed class` with a base class and an interface, `internal static class`, `public abstract class`, `public readonly struct`, `public readonly record struct`, `public sealed record`, `internal interface` with a generic constraint, `file sealed class`, and `public partial class` (opt-in partial); each one compiling with zero errors; and rejection tests asserting `ArgumentException` for every illegal combination listed below with the writer left empty.

## Constraints
- `NewTypeModel` is a `sealed record` with `Name`, `Kind` (`TypeDeclarationKind`), `Accessibility`, and init properties defaulting to false/empty: `IsStatic`, `IsAbstract`, `IsSealed`, `IsReadOnly`, `IsRefLikeType`, `IsPartial`, `TypeParameters` (`EquatableArray<TypeParameterModel>`), `BaseTypes` (`EquatableArray<TypeRef>`, written in order, base class first). Value-equal, no symbols.
- Modifier order: accessibility, `static`/`abstract`/`sealed`, `readonly`, `ref`, `partial`, kind keyword. `file` is written for `Accessibility.NotApplicable` only when a new `IsFileLocal` init flag is set; otherwise `NotApplicable` writes no accessibility.
- Reject before writing: `static` with `abstract`, `sealed` or base types; `abstract` with `sealed`; `static`/`abstract`/`sealed` on a struct, record struct or interface; `readonly` or `ref` on a class, record or interface; `ref` on a record struct; a blank name.
- Reuse `AppendTypeParameterList`/`AppendWhereClauses`; `WriteTypeDeclaration` and `WriteTypeDeclarationLine` output stays byte-identical.
- Returns `SourceWriter.BlockScope` (no containing types: nesting is the caller's or 13.2's job).
- TDD: show the first output test failing before the code.
- Edit only with Rider MCP tools; never write files via Bash.

## Out of scope
- Scoped-writer integration (13.2), primary constructors, enums, delegates, `new`/`unsafe` modifiers.
- Notes: prerequisites 3.1, 3.4 and 4.2. Raised in the handoff (builders for new non-partial types). If this exceeds the budget, split the rejection rules into 13.1b.
