# 17.1 C# 15 test project

## Goal
A new test project `tests/Haitch.Roslyn.CSharp15.Tests` compiles C# 15 sources (a union and a `closed` record) through `GeneratorHarness` with zero errors, and runs as part of `dotnet test` from the repo root.

## Touches
- `tests/Haitch.Roslyn.CSharp15.Tests/Haitch.Roslyn.CSharp15.Tests.csproj` (new)
- `tests/Haitch.Roslyn.CSharp15.Tests/CSharp15Polyfills.cs` (new)
- `tests/Haitch.Roslyn.CSharp15.Tests/CSharp15.cs` (new: shared `CSharpParseOptions` at `LanguageVersion.Preview`)
- `tests/Haitch.Roslyn.CSharp15.Tests/CSharp15SmokeTests.cs` (new)
- `Haitch.Roslyn.slnx`

## Acceptance
`dotnet test` from the repo root passes the full suite, including `CSharp15SmokeTests` that run a trivial generator via `GeneratorHarness` over `public union Pet(Cat, Dog);` and `public closed record Shape;` with zero diagnostics, and a test that the same sources fail at `LanguageVersion.CSharp14`.

## Constraints
- net10.0, TUnit, same settings as `tests/Haitch.Roslyn.Tests` (nullable, warnings as errors). It consumes Haitch.Roslyn and Haitch.Roslyn.Testing the same way the main test project does.
- `Microsoft.CodeAnalysis.CSharp` 5.9.0 via `VersionOverride` in this csproj only; `Directory.Packages.props` and the main test project stay on 4.12.0.
- Polyfills are compilation sources passed to the harness (not compiled into the test assembly): `System.Runtime.CompilerServices.IUnion`, `UnionAttribute`, `IsClosedTypeAttribute`, shaped as the .NET 11 runtime declares them. Prototype evidence: without them the compile fails with CS0518/CS0656.
- Pass Preview through the harness's existing `parseOptions` parameter; don't change `GeneratorHarness`.
- Later issues (17.3–17.7) add their C# 15 tests to this project.
- TDD: show the smoke test failing (e.g. missing polyfill, CS0518) before it passes. Edit only with Rider MCP tools.

## Out of scope
- CI changes (17.2), any change under `src/`.
