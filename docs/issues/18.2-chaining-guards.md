# 18.2 Chaining guards

## Goal
`ElseIf`, `Else`, `Catch`, `Finally`, `Case` and `Default` throw `InvalidOperationException` when a block nested inside the current branch is still open.

`dotnet test` from the repo root passes, including new `ScopeGuardTests` for each of the six methods with a nested `If` left open, asserting the throw and that nothing was written by the failed call.
