# 11.2 Sample generator reports member conflicts

## Goal
A `[Sample]` type that declares its own `ToString()` or a member named `TypeName` gets a `SAMPLE005` diagnostic and no generated file.

## Touches
- `tests/Haitch.Roslyn.Tests/Sample/SampleGenerator.cs`
- `tests/Haitch.Roslyn.Tests/Sample/SampleGeneratorTests.cs`

## Acceptance
`dotnet test` from the repo root passes the full suite, including new tests `Should_report_SAMPLE005_for_a_user_declared_ToString`, `Should_report_SAMPLE005_for_a_user_declared_TypeName_field` and `Should_report_SAMPLE005_when_the_conflict_is_in_another_part`, each asserting the exact diagnostic ids (`IsEquivalentTo(["SAMPLE005"])`) and an empty generated-source set, and `Should_generate_when_ToString_is_an_overload` (`ToString(string format)` is not a conflict; the full generated output string is asserted).

## Constraints
- Use `ForTypesWithAttribute(..., includeMembers: true)` from 11.1.
- Conflict rule: a method named `ToString` with zero parameters, or a field, property or method named `TypeName`. Report one `SAMPLE005` ("'{0}' already declares '{1}'") per conflicting name, located at the type's `SyntaxInfo.Location`; validation order stays partial checks first, then static, then conflicts.
- Remove the "Known gap" comment from the generator and replace it with one line naming what is still unguarded (nested types and events named `TypeName`).
- Existing sample outputs stay byte-identical; update `WidgetModel` or other expected models only as far as included members require, and say so in the report.
- `Should_be_cacheable_*` tests keep passing unchanged.
- TDD: show the `ToString` test failing with the real `CS0111` from the harness before the fix.
- Edit only with Rider MCP tools; never write files via Bash.

## Out of scope
- Skipping only the conflicting member instead of reporting (a deliberate choice: the generated `ToString` depends on `TypeName`).
- Nested types and events named `TypeName` (not modelled by `TypeModel`).
- Notes: prerequisite 11.1. Removes the gap documented in 8.2 and the handoff.
