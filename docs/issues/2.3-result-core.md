# 2.3 Result core

## Goal
`Result<T>` holds either a value or one or more `DiagnosticInfo`s, is value-equal, and supports `Map`, `Bind` and `Match`.

## Touches
- `src/Haitch.Roslyn/Diagnostics/Result.cs` (new)
- `tests/Haitch.Roslyn.Tests/Diagnostics/ResultTests.cs` (new)

## Acceptance
Rider test run of `ResultTests` passes, covering: success and failure construction, implicit conversion from `T` and from `DiagnosticInfo`, `Map`/`Bind` short-circuiting on failure, `Match`, and equality of two equal successes and two equal failures.

## Out of scope
- Combining multiple results (2.4), reporting (2.5).
- Warnings attached to a success (value plus non-error diagnostics) only if it falls out naturally; otherwise note it for a later issue.
