# 13.2 New types in the typed scoped writer

## Goal
`NewType(NewTypeModel)` on `FileScope`, `NamespaceScope` and `TypeScope` writes a new type through 13.1 and returns a `TypeScope` for its members.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/FileScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/NamespaceScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/NewTypeScopeTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes the full suite, including new `NewTypeScopeTests` asserting the full output for: a new class in a namespace with a field, method and property; a new interface with a default method; a new sealed class nested in a partial `TypeScope`; a new static class at file level; and a test that compiles each output with zero errors; plus `Should_reject_an_instance_field_in_a_new_interface` (same `ArgumentException` as for a partial interface).

## Constraints
- `TypeScope` keeps working from a `TypeModel`: build one internally from the `NewTypeModel` (namespace from the enclosing scope or null, no containing types) so the interface checks and the nested `Type(TypeModel)` containing-type check apply unchanged. Do not change `TypeModel`'s shape.
- Members written into a new interface keep their own accessibility (interface members stay `public` when the model says so; nothing is stripped).
- Blank-line separation matches `Type`; if 12.3 has landed, a pending `Attribute` attaches to `NewType` exactly as it does to `Type`.
- Top-level and nested rules differ (from the 13.1 review). `FileScope.NewType` and `NamespaceScope.NewType` reject `Private`, `Protected`, `ProtectedOrInternal` and `ProtectedAndInternal` accessibility, which would be CS1527. `TypeScope.NewType` rejects `IsFileLocal`, which would be CS9054. Each rejection throws `ArgumentException` before writing and is tested.
- Existing scope output stays byte-identical.

## Out of scope
- Rejecting instance members inside a new static class (CS0708 is the caller's error; document it on `NewType`).
- Primary constructors and records' positional parameters.
- Notes: prerequisites 13.1 and 10.1–10.5; run after 12.3 because both touch the three scope files.
