# 1.1 EquatableArray value equality

## Goal
Two `EquatableArray<T>` instances with equal elements in the same order are equal and have equal hash codes, and a default instance equals an empty one.

## Touches
- `src/Haitch.Roslyn/Types/EquatableArray.cs`
- `tests/Haitch.Roslyn.Tests/Types/EquatableArrayTests.cs`

## Acceptance
Rider test run of `EquatableArrayTests` passes, covering: equal contents, different order, different length, default vs empty, `==`/`!=`, `Equals(object)`, and hash equality for equal contents.

## Out of scope
- Enumeration, spans, conversions (1.2).
- Notes: wrap a `T[]`; constrain `T : IEquatable<T>`; use `EqualityComparer<T>.Default`. Hashing must not depend on `System.HashCode` unless Polyfill provides it on `netstandard2.0`.
