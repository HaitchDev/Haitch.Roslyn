# 24.2 ForPropertiesWithAttribute and ForFieldsWithAttribute

## Goal
`ForPropertiesWithAttribute` and `ForFieldsWithAttribute` yield one item per attributed property or field with its model, containing `TypeModel`, `SyntaxInfo` and attributes.

## Touches
- `src/Haitch.Roslyn/Generators/SyntaxValueProviderExtensions.cs`
- `tests/Haitch.Roslyn.Tests/Generators/MemberDiscoveryTests.cs`

## Acceptance
`.claude/check.sh` exits 0, including: auto and full properties; a partial property yields one item; an indexer yields nothing; `[Foo] int a, b;` yields two field items; a field-targeted attribute on an auto property (`[field: Foo]`) yields nothing from either method; `AssertCacheable` passes for both steps.

## Constraints
- Same tuple shape as 24.1 with `PropertyModel Property` / `FieldModel Field`.
- Property predicate: `PropertyDeclarationSyntax`. Field predicate: `VariableDeclaratorSyntax` whose grandparent is `FieldDeclarationSyntax` (that is the node `ForAttributeWithMetadataName` reports).
- Share the transform plumbing with 24.1 rather than copying it.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Indexers, events, custom predicates.
