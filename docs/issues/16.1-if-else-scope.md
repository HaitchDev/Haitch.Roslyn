# 16.1 If/else statement scopes

## Goal
`BodyScope.If(condition)` returns an `IfScope` whose `ElseIf(condition)` and `Else()` close the open branch and open the next one, producing a compiling `if`/`else if`/`else` chain.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/BodyScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/IfScope.cs` (new `ref struct`)
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/StatementScopeTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes the full suite, including new `StatementScopeTests` asserting the full output of a lone `if`, `if`/`else`, `if`/`else if`/`else` and an `if` nested in an `else`, a test that compiles each inside a method with zero errors, a `ScopeCompileCheck` test that `Else()` followed by `ElseIf` does not compile (exact id, CS1061 since `Else` returns `BodyScope`), and blank-condition rejection with the writer untouched.

## Constraints
- `IfScope` exposes `Line` and `Block` (and any 16.x statements present) like `BodyScope`, plus `ElseIf` and `Else`; `Else` returns `BodyScope`. Disposing an `IfScope` after a branch was chained is a no-op for the already-closed block (shared `State`, as in `PropertyScope`).
- Output form: `if (condition)` on its own line, braces on their own lines, `else`/`else if (...)` on the line after the closing brace.
- The condition is written as given (no extra parentheses beyond the `if ( )`).
- Existing `BodyScope` output stays byte-identical.
