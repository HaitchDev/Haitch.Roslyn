# 22.2 Check script and CI format step

## Goal
`.claude/check.sh` restores, builds, checks formatting and runs the tests, and CI fails on unformatted code.

## Touches
- `.claude/check.sh` (new, executable)
- `.github/workflows/ci.yml`

## Acceptance
`.claude/check.sh` exits 0 from the repo root.

## Constraints
- Red: show the script exiting non-zero with one deliberately misformatted file, then revert that file.
- Steps in order, stopping at the first failure (`set -euo pipefail`): `dotnet tool restore`, `dotnet restore`, `dotnet build --no-restore`, `dotnet csharpier check .`, `dotnet test --no-build`. Warnings are already errors via `Directory.Build.props`; do not duplicate.
- Works from any working directory (cd to the repo root from the script's own path).
- Git mode is 100755.
- CI `build` job: add `dotnet tool restore` and `dotnet csharpier check .` after restore; leave the `dotnet11` job and `publish.yml` alone.

## Out of scope
- Running `tools/test-dotnet11.sh` from the check, pre-commit hooks.
