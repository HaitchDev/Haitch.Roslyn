# 32.1 Explicit usings in Haitch.Roslyn.Testing

## Goal
`Haitch.Roslyn.Testing` builds with `ImplicitUsings` off, every file declaring the usings it needs.

## Touches
- `src/Haitch.Roslyn.Testing/Haitch.Roslyn.Testing.csproj`
- Every `.cs` file in `src/Haitch.Roslyn.Testing/` that the compiler flags. This is a mechanical, compiler-driven change and is exempt from the five-file rule, as 22.1 was. List each file in the report.

## Acceptance
`.claude/check.sh` exits 0, and `grep -c ImplicitUsings src/Haitch.Roslyn.Testing/Haitch.Roslyn.Testing.csproj` prints 0.

## Constraints
- Remove the `ImplicitUsings` element; do not set it to `disable` or add a `GlobalUsings.cs` or any `global using`.
- Add only the usings each file needs. Do not change any code, signature or XML doc text beyond usings (a cref that no longer resolves may be fully qualified instead).
- Red/green here: the Acceptance grep prints 1 before and 0 after, and the first build after removing the element fails; show the grep both times and the error count of that failing build.
- Edit only with Rider MCP tools.

## Out of scope
- `ImplicitUsings` in test and sample projects.
- Any other cleanup in the Testing project.
