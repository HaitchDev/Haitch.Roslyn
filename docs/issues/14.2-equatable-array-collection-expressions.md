# 14.2 EquatableArray collection expressions

## Goal
`EquatableArray<int> values = [1, 2, 3];` compiles in shipped code and in a netstandard2.0 consumer of the package.

## Touches
- `src/Haitch.Roslyn/Types/EquatableArray.cs` (add `[CollectionBuilder(typeof(EquatableArray), nameof(EquatableArray.Create))]` and a non-generic `internal static class EquatableArray` with `Create<T>(ReadOnlySpan<T>)`)
- `tests/Haitch.Roslyn.Tests/Types/EquatableArrayAccessTests.cs`
- `tests/PackageSmoke/Consumer/Usage.cs`

## Acceptance
`dotnet test` from the repo root passes the full suite, including new tests that `[1, 2, 3]` equals `new EquatableArray<int>([1, 2, 3])`, that `[]` equals `default` with equal hash codes, that a spread `[.. existing, 4]` has the expected elements, and `PackageSmokeTests` with the consumer using a collection expression.

## Constraints
- `CollectionBuilderAttribute` comes from Polyfill 11.4.0 (its netstandard2.0 source is gated on `FeatureMemory`, which is defined because System.Memory 4.5.5 reaches the project through Roslyn). No new package. If the consumer build reports CS0246 for the attribute, stop and report: that needs the human.
- `Create` copies the span once into an owned array (adopt via `FromOwnedArray`); an empty span yields `default`.
- Since 14.1, `EquatableArray<T>` implements `IEnumerable` and has a parameterless constructor, so `[]` already compiles through the collection-initializer path (from the 14.1 review). The TDD red must use a non-empty literal such as `[1, 2, 3]` (today CS1061, no `Add`). Also prove that after the change `[]` binds to `Create` and equals `default`, not `new EquatableArray<T>()` by accident.
- Value equality, hash codes and cacheability are unchanged.
- TDD: show the collection-expression test failing (CS9174 or CS1061) before the change.
- Edit only with Rider MCP tools; never write files via Bash.

## Out of scope
- Migrating existing `ToEquatableArray()` call sites to collection expressions.
- Notes: prerequisite 14.1 (a collection-builder type must be enumerable) and 0.7.
