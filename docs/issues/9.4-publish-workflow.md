# 9.4 Publish workflow

## Goal
`.github/workflows/publish.yml` publishes both packages to nuget.org through trusted publishing when a `v*.*.*` tag is pushed.

## Touches
- `.github/workflows/publish.yml` (new)

## Acceptance
`actionlint .github/workflows/publish.yml` exits 0, and running the workflow's pack command locally (`dotnet pack -c Release -p:Version=1.2.3 -o "$TMPDIR/haitch-publish"`) produces `Haitch.Roslyn.1.2.3.nupkg`, `Haitch.Roslyn.Testing.1.2.3.nupkg` and `Haitch.Roslyn.Testing.1.2.3.snupkg`.

## Out of scope
- Pushing a tag, running the workflow, creating secrets, or configuring the nuget.org trusted publishing policy.
- Notes: NEEDS HUMAN: `actionlint` is not installed (`brew install actionlint`), and before the first release a human must add the `NUGET_USER` secret and a trusted publishing policy on nuget.org for `HaitchDev/Haitch.Roslyn` / `publish.yml`. Prerequisites: 9.2. Base it on Haitch.Unions' `publish.yml` (permissions `id-token: write`, `NuGet/login@v1`, push `*.nupkg` then `*.snupkg` with `--skip-duplicate`), but install the SDK with `actions/setup-dotnet@v4` `global-json-file: global.json` instead of a hard-coded version, and run tests with `dotnet test -c Release --no-build` (the repo uses the Microsoft.Testing.Platform runner via `global.json`). Version is `${GITHUB_REF_NAME#v}`. `fetch-depth: 0` for SourceLink.
