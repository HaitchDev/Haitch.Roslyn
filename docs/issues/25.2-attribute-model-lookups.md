# 25.2 AttributeModel lookups

## Goal
`AttributeModel` finds arguments by name or position, and `EquatableArray<AttributeModel>.Find` finds an attribute by fully qualified metadata name.

## Touches
- `src/Haitch.Roslyn/Models/AttributeModel.cs`
- `src/Haitch.Roslyn/Models/AttributeModelExtensions.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/AttributeModelLookupTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including: named hit, named miss, ordinal name match only (`name` ≠ `Name`); constructor index in range, out of range (false, no throw) and a `params` argument (one `Array` value); `Find` for a plain, a nested (`Outer+Inner`) and a generic (`Foo`1`) attribute, and a miss returning null.

## Constraints
- `TryGetNamedArgument(string name, out ConstantValue value)`, `TryGetConstructorArgument(int index, out ConstantValue value)`; `Find(this EquatableArray<AttributeModel>, string fullyQualifiedMetadataName)` returns `AttributeModel?`.
- `Find` takes the same name form as `ForAttributeWithMetadataName`. If `TypeRef` cannot produce that form without a model change, stop and report: that is an orchestrator decision.
- Explicit usings only; fully qualify crefs outside imported namespaces.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- `FindAll`, matching by short name or by `Attribute` suffix.
