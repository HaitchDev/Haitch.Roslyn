# 39.20 IsOrImplements a constructed generic interface

## Goal
`type.IsOrImplements(metadataName, typeArgument)` is true when the type is, or implements, the generic definition named `metadataName` constructed with exactly `typeArgument` as its single type argument (symbol equality), e.g. a struct implementing `IEquatable<Other>` but not `IEquatable<Itself>` answers false for `("System.IEquatable`1", itself)`; the one-argument `IsOrImplements(metadataName)` is unchanged.
