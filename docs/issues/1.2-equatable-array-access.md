# 1.2 EquatableArray enumeration and conversions

## Goal
`EquatableArray<T>` can be enumerated, indexed, viewed as a span, and created from arrays, `ImmutableArray<T>` and enumerables.

## Touches
- `src/Haitch.Roslyn/Types/EquatableArray.cs`
- `src/Haitch.Roslyn/Types/EquatableArrayExtensions.cs` (new)
- `tests/Haitch.Roslyn.Tests/Types/EquatableArrayAccessTests.cs` (new)

## Acceptance
Rider test run of `EquatableArrayAccessTests` passes, covering: `Count`, `IsEmpty`, indexer, `foreach`, `AsSpan`, `ToEquatableArray()` from `T[]`, `ImmutableArray<T>` (including default) and `IEnumerable<T>`, and that mutating the source array after creation does not change the `EquatableArray`.

## Out of scope
- Dictionary or set variants.
- LINQ-style helpers beyond the conversions.
