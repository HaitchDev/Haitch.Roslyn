# 36.1 Diagnostics from the result pipeline are suppressible

## Goal
A diagnostic reported through the result pipeline is suppressed by `#pragma warning disable` or `[SuppressMessage]` in user code, because its location is bound to the compilation's syntax tree.

## Touches
- `src/Haitch.Roslyn/Diagnostics/LocationInfo.cs`
- `src/Haitch.Roslyn/Diagnostics/DiagnosticInfo.cs`
- `src/Haitch.Roslyn/Diagnostics/ResultPipelineExtensions.cs`
- `tests/Haitch.Roslyn.Tests/Diagnostics/LocationSuppressionTests.cs` (exists, failing)
- `tests/Haitch.Roslyn.Tests/Diagnostics/ResultPipelineExtensionsTests.cs`

## Acceptance
`.claude/check.sh` exits 0, including `LocationSuppressionTests` and the new pragma test in `ResultPipelineExtensionsTests`.

## Constraints
- The existing probe tests are the red; run them first and include the failure in the report. Change them to call `ToLocation(compilation)`, and reformat the file with csharpier (it currently fails `csharpier check`).
- Add `LocationInfo.ToLocation(Compilation)`. It returns a location in the one syntax tree whose `FilePath` equals `FilePath`. It falls back to `ToLocation()` when no tree matches, when several match, or when the span runs past the end of the tree. Test each fallback.
- Add `DiagnosticInfo.ToDiagnostic(Compilation)` and a `ReportDiagnostics(SourceProductionContext, EquatableArray<DiagnosticInfo>, Compilation)` overload.
- `ReportDiagnostics<T>` combines only its diagnostics branch with `CompilationProvider`. The value and source outputs must stay cached; the existing cacheability tests prove it and must keep passing.
- `LocationInfo` and `DiagnosticInfo` hold no `SyntaxTree`, `Location` or `Compilation`. A design check showed that a stored tree either goes stale or breaks the trivia-edit cacheability check.
- Keep the parameterless `ToLocation()`/`ToDiagnostic()` for locations outside the compilation (such as additional files), with a one-line comment saying why.
- Add a `ResultPipelineExtensionsTests` test where a generator reports through the result pipeline at a span under `#pragma warning disable TEST001`, and the driver's diagnostic has `IsSuppressed = true`. Mutation check: switch the pipeline back to the parameterless `ToDiagnostic()` and show the test fails.
- `src/` compiles against Roslyn 4.12. A worker owns every failure in the full suite. Edit only with Rider MCP tools.

## Out of scope
- The sample generators and additional-file diagnostics.
- The docs site.
- Moving diagnostics into a separate analyzer.
