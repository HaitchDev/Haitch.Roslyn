# 10.7 Partial property implementation

## Goal
Writing the implementation of a user-declared C# 13 `partial` property through the typed writer produces a declaration that compiles alongside it.

## Touches
- `src/Haitch.Roslyn/Models/PropertyModel.cs` (add `IsPartial`, `HasExplicitAccessibility` and `IsReadOnly`)
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs` (render `partial` and `readonly`; skip implicit accessibility)
- `tests/Haitch.Roslyn.Tests/Models/MemberModelTests.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/PropertyAccessorScopeTests.cs` (or the 10.5 test file, whichever 10.5 created)

## Acceptance
`dotnet test` from the repo root passes the full suite, including new tests that build a `PropertyModel` from `public partial int X { get; set; }` and from `partial string Y { get; }`, write the implementation via the 10.5 accessor scopes, and compile the user declaration plus the output with zero errors.

## Constraints
- Follow 10.6: `HasExplicitAccessibility` is an init property defaulting to `true`, computed only for partial properties from the definition part's declaring syntax (`PartialDefinitionPart ?? property`); every other property keeps `true`, so interface members keep `public`.
- `IsPartial` is a value-equal `bool`; the model holds no syntax or symbols.
- Also from the 10.5 review: `RenderPropertyHeader` writes `sealed` when `IsSealed` is set without `IsOverride`, as for a sealed interface default property. Add a compile test.
- `IsReadOnly` means the `readonly` member modifier (a `readonly` property in a non-readonly struct). `IPropertySymbol.IsReadOnly` means "has no setter", so do not use it. Derive the flag from the accessor methods' `IMethodSymbol.IsReadOnly`, true when every accessor is readonly and the containing type is not a `readonly struct`. Render it as `readonly` in the property header so a `readonly partial` property's implementation matches. Raised in the 10.5 review.
- Existing property rendering stays byte-identical for non-partial properties.

## Out of scope
- `AutoProperty` for partial properties (the implementing part needs accessor bodies).
- Partial events and indexers.
- Notes: prerequisites 10.5 and 10.6. Raised in the 10.4 report.
