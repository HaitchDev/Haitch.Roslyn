# 0.4 Test runner on the .NET 10 SDK

## Goal
`dotnet test` at the repo root and Rider's test runner both run the TUnit suite to completion on the .NET 10 SDK.

## Touches
- `global.json` (new)
- `tests/Haitch.Roslyn.Tests/Haitch.Roslyn.Tests.csproj`

## Acceptance
`dotnet test` run from the repo root via `mcp__rider__execute_terminal_command` exits 0 and reports the full suite; the same tests pass when run through Rider's test runner.

## Out of scope
- Any test or source change.
- Notes: on the .NET 10 SDK, `dotnet test` with Microsoft.Testing.Platform is enabled by `global.json` (`"test": { "runner": "Microsoft.Testing.Platform" }`), and the VSTest bridge property `TestingPlatformDotnetTestSupport` is no longer supported. Confirm against current Microsoft docs (microsoft-learn MCP) before changing anything.
