# 37.1 TypeRef carries type arguments

## Goal
`TypeRef.From` on a constructed generic type exposes its type arguments as `TypeRef`s, so a generator reads `Person` from a `TypeModel.BaseType` of `Validator<Person>`.

## Touches
- `src/Haitch.Roslyn/Models/TypeRef.cs`
- `tests/Haitch.Roslyn.Tests/Models/TypeRefTests.cs`
- `tests/Haitch.Roslyn.Tests/Models/TypeModelTests.cs`

## Acceptance
`.claude/check.sh` exits 0, including the new `TypeArguments` tests in `TypeRefTests` and the generic-base test in `TypeModelTests`.

## Constraints
- Add `EquatableArray<TypeRef> TypeArguments` as an init property, not a positional parameter, so existing `new TypeRef(...)` calls compile unchanged. It is empty for non-generic types and for types built with the constructor.
- `From` fills it from `INamedTypeSymbol.TypeArguments` in order, recursively (`Dictionary<string, List<int>>` nests). Array, pointer and type-parameter symbols get an empty array.
- Two `TypeRef`s with the same name but different `TypeArguments` are not equal, and equal ones have equal hash codes. Test both.
- Extend the existing generic-base test in `TypeModelTests` so it asserts `BaseType.TypeArguments` holds `int` (`global::System.Int32` display name or `SpecialType.System_Int32`, whichever the model already uses).
- TDD in tiny steps, one hat at a time: each behaviour step starts from a test seen failing for the right reason, then the minimum code to pass; refactors are separate steps with tests green.
- Commit every step: the failing test alone as `test: ...`, then `feat: ...` to green it, and each refactor as its own `refactor: ...`. Lowercase conventional subject only, no body, no trailers. Stage paths explicitly. Commit this issue file first as `docs: add issue 37.1 type ref type arguments`.
- Rider MCP is not available to this worker: edit with Edit/Write (not `sed -i`), build and test with the dotnet CLI, format with `dotnet csharpier format` on touched files.
- `src/` compiles against Roslyn 4.12.

## Out of scope

- Any change to `TypeModel`, `ForTypesWithAttribute`, or other models.
- `docs/handoff.md` and the issue index in `docs/issues/README.md`.
