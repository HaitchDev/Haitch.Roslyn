# 17.2 .NET 11 CI job

## Goal
`tools/test-dotnet11.sh` builds and tests the solution on the .NET 11 SDK without touching the working tree's `global.json`, and CI runs it as a second job.

## Touches
- `tools/test-dotnet11.sh` (new, executable)
- `.github/workflows/ci.yml`

## Acceptance
`tools/test-dotnet11.sh` exits 0 locally (SDK 11.0.100-rc.1 is installed), and `git diff --exit-code global.json` exits 0 afterwards.

## Constraints
- The script copies the repo (excluding `bin/`, `obj/`, `.git/`) to a temp dir, rewrites the copy's `global.json` to select an 11.0 SDK (`allowPrerelease: true`, keeping the `test.runner` section), then runs restore, build `-c Release` and test. It prints the SDK version it used.
- The new CI job installs the 11.0 SDK with `actions/setup-dotnet` (`dotnet-quality: preview`) alongside the existing job, and calls the script. The existing job is unchanged.
- The script is written with the Rider MCP tools (create file), then `chmod +x`.

## Out of scope
- Switching the repo's default SDK, multi-targeting net11.0, publish workflow.
- Notes: prerequisite 17.1.
