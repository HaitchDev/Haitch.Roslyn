# 12.1 Render an attribute list from AttributeModel

## Goal
`SourceWriterExtensions.WriteAttribute(writer, attribute)` writes an `AttributeModel` as one `[global::...(...)]` line that compiles.

## Touches
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs` (add `WriteAttribute`, `WriteAttributes` and an `internal static string RenderAttribute(AttributeModel)`; reuse `RenderConstant`)
- `tests/Haitch.Roslyn.Tests/Writing/AttributeRenderingTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes the full suite, including new `AttributeRenderingTests` that build `AttributeModel`s from symbols and assert the full rendered line for: no arguments (no parentheses), constructor arguments of every `ConstantValueKind` except `Error` (primitive, string with escapes, enum including a negative value, `typeof`, array, `null`), named arguments after positional ones, a `params` constructor, and a generic attribute; plus `Should_compile_a_type_decorated_with_the_rendered_attributes`, which compiles the attribute definitions with a type carrying every rendered line and asserts zero errors.

## Constraints
- The attribute type is written fully qualified from `AttributeType.FullyQualifiedName` (keep the `Attribute` suffix; it always resolves).
- `WriteAttributes` writes one line per attribute, in order, and writes nothing for an empty array.
- An `Error` constant argument throws `ArgumentException` before anything is written, so the writer is untouched (assert the writer's text is empty).
- No existing rendering changes: member and type output stays byte-identical, and model `Attributes` are not rendered automatically anywhere (copying a partial type's own attributes would raise CS0579).
- Tests assert whole strings, not `Contains`; compile failures report exact error ids.
- TDD: show the first rendering test failing (missing method, CS0117) before writing code.
- Edit only with Rider MCP tools; never write files via Bash.

## Out of scope
- Attribute targets (`[return: ...]`, `[assembly: ...]`) and parameter attributes.
- Well-known attribute factories (12.2) and scoped-writer support (12.3).
- Notes: prerequisites 3.2 and 4.2. Raised in the handoff ("SourceWriterExtensions does not render attribute lists").
