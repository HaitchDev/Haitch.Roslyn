# 5.1 ForAttributeWithMetadataName wrappers

## Goal
A `SyntaxValueProvider` extension finds types marked with an attribute and returns `IncrementalValuesProvider<(TypeModel, SyntaxInfo, EquatableArray<AttributeModel>)>`, one item per marked declaration, cache-friendly end to end.

## Touches
- `src/Haitch.Roslyn/Generators/SyntaxValueProviderExtensions.cs` (new)
- `tests/Haitch.Roslyn.Tests/Generators/SyntaxValueProviderExtensionsTests.cs` (new)

## Acceptance
Rider test run of `SyntaxValueProviderExtensionsTests` passes: a test generator using the extension finds marked types, and an edit unrelated to marked types leaves every tracked step `Cached` or `Unchanged` on the second run.

## Out of scope
- Methods or properties as targets.
- Notes: the predicate filters to `TypeDeclarationSyntax` (`SyntaxInfo.From` takes that type; enums are not supported targets). `SyntaxInfo` holds a location that shifts when text above it changes, so the cached-run test must make its unrelated edit in a different file.
