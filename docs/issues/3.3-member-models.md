# 3.3 Member models

## Goal
`ParameterModel`, `PropertyModel`, `MethodModel` and `FieldModel` capture their symbols as value-equal data including name, type, accessibility, modifiers and attributes.

## Touches
- `src/Haitch.Roslyn/Models/ParameterModel.cs` (new)
- `src/Haitch.Roslyn/Models/PropertyModel.cs` (new)
- `src/Haitch.Roslyn/Models/MethodModel.cs` (new)
- `src/Haitch.Roslyn/Models/FieldModel.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/MemberModelTests.cs` (new)

## Acceptance
Rider test run of `MemberModelTests` passes, covering: parameter ref kinds and default values, property accessors and `init`/`required`, method return type, generics and static/async/partial, field readonly/const, and equality across two compilations.

## Out of scope
- `TypeModel` (3.4), events, operators, indexers.
