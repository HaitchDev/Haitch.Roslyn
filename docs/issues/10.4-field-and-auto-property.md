# 10.4 Fields and auto-properties

## Goal
`TypeScope` writes one correct declaration line per `FieldModel` (`Field(model, initializer)`) or `PropertyModel` (`AutoProperty(model)`).

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs` (add internal field and property header rendering beside the existing helpers)
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/FieldAndPropertyScopeTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `FieldAndPropertyScopeTests`: rendered lines for a `private static readonly` field with an initializer, a `public const` field from its `ConstantValue`, a `required` property, a `{ get; private set; }` property and a `{ get; init; }` property; a type containing all of them compiles with Roslyn without errors.

## Out of scope
- Properties with accessor bodies (10.5); attributes on members (the existing writer does not render attribute lists either).
- Notes: prerequisites: 10.3 (same `TypeScope.cs`). Reuse `AppendAccessibility` and `RenderConstant`; type names come from `TypeRef` exactly as `WriteMethodSignature` renders them. `initializer` is an optional raw expression string; a `const` field uses its `ConstantValue` and rejects an explicit initializer. Accessor accessibility is written only when it differs from the property's.
