# 39.16 BodyScope opens a block without a header

## Goal
`BodyScope.Block()` (no header) writes `{`, returns a nested `BodyScope` for its body, and disposing it writes `}`, so consumers write a bare statement block (for local scoping) without dropping to `SourceWriter.Block()`.

## Constraints
- Found by Haitch.Validation 082: its generator writes a bare `{ ... }` around a member's multi-rule check; `BodyScope.Block(header)` rejects a blank header, and `SourceWriter.Block()` freezes the outer `BodyScope` until it closes. Only `BodyScope` gets the overload (a bare block is a statement; type level has none, and no consumer needs it on `IfScope`/`TryScope`).
