# 17.7 Labeled loops and jumps

## Goal
`ForEach`/`For`/`While`/`Switch` take an optional label that is written before the statement, and `BodyScope.Break(label)`/`Continue(label)` write labeled jumps that compile under C# 15.

## Touches
- `src/Haitch.Roslyn/Writing/SourceWriter.cs`
- `src/Haitch.Roslyn/Writing/Scopes/BodyScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/IfScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/TryScope.cs`
- `tests/Haitch.Roslyn.CSharp15.Tests/LabeledJumpTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `LabeledJumpTests`: exact output and compile (zero diagnostics, CS0164 counts as failure) for `outer:` on a `for` with `continue outer;` and `break outer;` from a nested loop, and a labeled switch with `break label;`; `ArgumentException` (writer untouched) for a label that isn't an identifier, a jump to a label that isn't open, and `Continue` naming a switch.

## Constraints
- Labels are tracked in a stack on `SourceWriter` (name + loop/switch), pushed when the labeled statement opens and popped when it closes.
- The label goes on its own line before the statement: `outer:` then `for (...)`.
- The parameter is optional and last; existing calls and output stay unchanged. If 18.5 already added unlabeled `Break()`, reuse it with an optional label.
