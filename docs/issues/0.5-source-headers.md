# 0.5 Source header enforcement

## Goal
A test fails when any `.cs` file under `src/Haitch.Roslyn` does not start with `// <auto-generated/>` followed by `#nullable enable`.

## Touches
- `tests/Haitch.Roslyn.Tests/SourceHeaderTests.cs` (new)
- `src/Haitch.Roslyn/Types/EquatableArray.cs` (header only)

## Acceptance
`dotnet test` passes; `SourceHeaderTests` is red before the header is added to `EquatableArray.cs` and green after.

## Out of scope
- Any change to `EquatableArray` behaviour (1.1).
- Notes: locate `src/Haitch.Roslyn` from the test by walking up from `AppContext.BaseDirectory` to the directory containing `global.json`; exclude `bin` and `obj`.
