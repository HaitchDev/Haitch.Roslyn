# 39.21 NamespaceScope writes a using directive inside the namespace

## Goal
`NamespaceScope.Using(string namespaceName)` writes `using {namespaceName};` inside the namespace block, before the namespace's first member (same ordering and duplicate rules as `FileScope.Using`), so a generator can reproduce a source file's in-namespace usings.

- the `NamespaceScope` writer test file
