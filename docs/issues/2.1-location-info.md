# 2.1 LocationInfo

## Goal
`LocationInfo` captures a Roslyn `Location` as value-equal data and converts back to an equivalent `Location`.

## Touches
- `src/Haitch.Roslyn/Diagnostics/LocationInfo.cs` (new)
- `tests/Haitch.Roslyn.Tests/Diagnostics/LocationInfoTests.cs` (new)

## Acceptance
Rider test run of `LocationInfoTests` passes, covering: `From(Location)` for a source location in a parsed syntax tree, `From` returning null for `Location.None`/metadata locations, round-trip `ToLocation()` preserving path, span and line span, and equality of two captures of the same location from separately parsed identical trees.

## Out of scope
- Diagnostics (2.2).
- Notes: a `record` holding file path, `TextSpan` and `LinePositionSpan`.
