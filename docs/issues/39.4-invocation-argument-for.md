# 39.4 An invocation's argument is found by parameter name

## Goal
`call.ArgumentFor(model, "parameter", cancellationToken)` on an `InvocationExpressionSyntax` returns the value operation bound to that parameter, however the caller wrote it (positional, named, named out of order, extension method called on its receiver), and `null` when the argument is omitted or the call does not bind, so a generator reads rule arguments without walking `IInvocationOperation` by hand.

## Constraints
- Found in Haitch.Validation's generator (`RuleArguments.ArgumentOperation`/`ArgumentByParameter`), which matches `IArgumentOperation.Parameter.Name` on the invocation's operation. Returned value: the argument's `Value` operation (so `ConstantValue`, `ITypeOfOperation`, lambdas are reachable). An omitted optional parameter returns `null`, not the default-value operation the compiler supplies. An extension method's `this` parameter is reachable by its name.
