# 2.4 Result combine

## Goal
Combining several results returns all values when every result succeeds, and every diagnostic from every failure otherwise.

## Touches
- `src/Haitch.Roslyn/Diagnostics/Result.cs`
- `tests/Haitch.Roslyn.Tests/Diagnostics/ResultCombineTests.cs` (new)

## Acceptance
Rider test run of `ResultCombineTests` passes, covering: `Combine` of two and three results into a tuple, `Collect` of `IEnumerable<Result<T>>` into `Result<EquatableArray<T>>`, all-success, one failure, and multiple failures keeping all diagnostics in order.

## Out of scope
- Reporting (2.5).
- Async or LINQ query-syntax support.
