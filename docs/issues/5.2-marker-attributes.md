# 5.2 Marker attribute emission

## Goal
A post-initialisation helper emits a marker attribute source marked `[global::Microsoft.CodeAnalysis.EmbeddedAttribute]`, so marker attributes never collide across assemblies.

## Touches
- `src/Haitch.Roslyn/Generators/PostInitializationExtensions.cs` (new)
- `tests/Haitch.Roslyn.Tests/Generators/PostInitializationExtensionsTests.cs` (new)

## Acceptance
Rider test run of `PostInitializationExtensionsTests` passes: a test generator emits an attribute with chosen targets, namespace and properties; the output compiles, the attribute is internal and embedded, and two assemblies emitting it can be referenced together without CS0436.

## Out of scope
- Non-attribute post-initialisation sources.
- Notes: Roslyn 4.8 has no `AddEmbeddedAttributeDefinition`; emit the `EmbeddedAttribute` definition too.
