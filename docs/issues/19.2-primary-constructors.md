# 19.2 Primary constructors and positional records

## Goal
`NewTypeModel.PrimaryConstructorParameters` writes a parameter list after the type name for classes, structs and records, producing positional records and primary constructors that compile.

## Touches
- `src/Haitch.Roslyn/Models/NewTypeModel.cs`
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs`
- `tests/Haitch.Roslyn.Tests/Writing/NewTypeDeclarationTests.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/NewTypeScopeTests.cs`

## Acceptance
`dotnet test` from the repo root passes, including exact output and compile for `public record Person(string Name, int Age);` (no body), a record struct with a body, a class with a primary constructor and a base type, and a generic positional record with constraints; and `ArgumentException` (writer untouched) for parameters on an interface, a static class or a union.

## Constraints
- `PrimaryConstructorParameters` is an `init` `EquatableArray<ParameterModel>?`: null means no list, empty means `()`. Parameters render with the existing parameter rendering (defaults, ref kinds, `params`).
- The list goes after type parameters and before the base list and where clauses.
- A positional record with no body ends with `;` when written via `WriteNewTypeDeclaration` with no members; via the scoped `NewType()` it keeps a body.

## Out of scope
- Base-constructor arguments (`: Base(x)`), modelling primary constructors in `TypeModel`.
