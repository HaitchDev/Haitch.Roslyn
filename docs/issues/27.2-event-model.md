# 27.2 EventModel

## Goal
`TypeModel.From(..., includeMembers: true)` records the type's events as equatable `EventModel`s.

## Touches
- `src/Haitch.Roslyn/Models/EventModel.cs` (new)
- `src/Haitch.Roslyn/Models/TypeModel.cs`
- `tests/Haitch.Roslyn.Tests/Models/EventModelTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including tests for: a field-like event; an event with custom `add`/`remove`; a static event; an explicit interface event; a nullable delegate type (`EventHandler?`); `Events` empty when `includeMembers` is false; and equality of two `From` calls.

## Constraints
- `internal sealed record EventModel(string Name, TypeRef Type, Accessibility Accessibility, bool IsStatic, bool IsFieldLike)`, with `init` extras for explicit implementations, abstract/virtual/override/sealed and attributes. Read `PropertyModel`/`MethodModel` and match their naming and precedents.
- `IsFieldLike` is true when the add/remove accessors are implicitly declared.
- `static EventModel From(IEventSymbol, CancellationToken = default)`.
- `TypeModel` gains `EquatableArray<EventModel> Events { get; init; }`, populated only with `includeMembers`.
