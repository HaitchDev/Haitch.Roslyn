# 28.1 TypeScope.Line

## Goal
`TypeScope.Line(string)` writes one raw line at the type body's indent, between members.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `tests/Haitch.Roslyn.Tests/Writing/TypeScopeLineTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including tests for: a line written at the type body's indent inside nested types; `#pragma warning disable CS0067` / `restore` around `Event(...)` producing output that compiles with no warnings under `#nullable enable` (read `result.Compilation.GetDiagnostics()`); output byte-identical to calling `SourceWriter.WriteLine` at the same point (the Notify sample's current pattern), including blank-line member spacing before and after; and `Line()` with no argument writing an empty line.

## Constraints
- Same signature and semantics as `BodyScope.Line` (`BodyScope.cs:38`); match its doc comment style.
- Must not change member spacing or buffered-attribute behaviour versus a direct `SourceWriter.WriteLine` at the same point; if a pending buffered attribute makes that impossible, throw `InvalidOperationException` and test it.
- TDD: behavioural red against a stub (e.g. a no-op `Line`), shown in the report. Edit only with Rider MCP tools.

## Out of scope
- Raw lines on `FileScope`, `NamespaceScope` or `PropertyScope`.
- Changing the Notify sample (28.2).
