# 17.4 Closed types in TypeModel

## Goal
`TypeModel.IsClosed` is true for a `closed` class or record, whether declared in source or referenced from metadata.

## Touches
- `src/Haitch.Roslyn/Models/TypeModel.cs`
- `tests/Haitch.Roslyn.CSharp15.Tests/ClosedModelTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `ClosedModelTests`: true for `public closed record Shape;` and for a closed class split across partial parts where only one part says `closed`; false for an abstract class; true for a closed type from a referenced metadata compilation; a generated partial part of a closed class compiles.

## Constraints
- Source: a modifier token with `ValueText == "closed"` on any declaring syntax reference. Metadata: read `IsClosed` on the host symbol by reflection, cached per type in a static; a missing property means false. The compiler hides `IsClosedTypeAttribute`, so don't look for it.
- `IsClosed` is an `init` property; `IsAbstract` keeps reporting what Roslyn says (true) but the partial-declaration writer never echoes `abstract`/`closed` (it doesn't today; keep a test).
- TDD: behavioural red first. Edit only with Rider MCP tools.
