# 25.1 ConstantValue typed accessors

## Goal
`ConstantValue` exposes typed `TryGet…` accessors that return false on a kind or type mismatch and never throw.

## Touches
- `src/Haitch.Roslyn/Models/ConstantValue.cs`
- `tests/Haitch.Roslyn.Tests/Models/ConstantValueAccessorTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including, for values built with `From(TypedConstant)` from real attribute usages: each accessor's hit and miss; `TryGetInt32` on a `long` argument returns false; `TryGetEnum<TEnum>` on an `int` enum and a `byte` enum; `TryGetType` returns the `TypeRef`; `TryGetArray` and `TryGetStringArray` (with a `null` element); every accessor returns false for `Null` and `Error`.

## Constraints
- Accessors: `TryGetString(out string)`, `TryGetBoolean`, `TryGetInt32`, `TryGetInt64`, `TryGetDouble`, `TryGetEnum<TEnum>(out TEnum) where TEnum : struct, Enum`, `TryGetType(out TypeRef)`, `TryGetArray(out EquatableArray<ConstantValue>)`, `TryGetStringArray(out EquatableArray<string?>)`; plus `bool IsNull`.
- Exact CLR type match for primitives: no widening or conversion. `TryGetEnum` converts the underlying value with `Enum.ToObject`; it does not check that the value is defined.
- `TryGetStringArray` fails if any element is neither `String` nor `Null`.
- Equality and existing factories are unchanged. Explicit usings only.

## Out of scope
- Binding a whole attribute to a user type, other primitive widths (add when needed).
