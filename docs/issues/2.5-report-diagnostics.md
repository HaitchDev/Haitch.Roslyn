# 2.5 Report diagnostics

## Goal
A generator can split a `Result<T>` pipeline into reported diagnostics and a stream of successful values.

## Touches
- `src/Haitch.Roslyn/Diagnostics/ResultPipelineExtensions.cs` (new)
- `tests/Haitch.Roslyn.Tests/Diagnostics/ResultPipelineExtensionsTests.cs` (new)
- `tests/Haitch.Roslyn.Tests/Diagnostics/TestGenerator.cs` (new, test-only generator)

## Acceptance
Rider test run of `ResultPipelineExtensionsTests` passes: a test generator driven by `CSharpGeneratorDriver` reports the expected diagnostics for failing inputs, generates output only for successful inputs, and a second run with an unchanged compilation reports the value step as `Cached`/`Unchanged`.

## Out of scope
- Model types (slice 3).
- Notes: provide `ReportDiagnostics(this SourceProductionContext, EquatableArray<DiagnosticInfo>)` and an `IncrementalValuesProvider<Result<T>>` extension that registers diagnostic reporting and returns `IncrementalValuesProvider<T>`.
