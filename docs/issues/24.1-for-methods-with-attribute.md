# 24.1 ForMethodsWithAttribute

## Goal
`ForMethodsWithAttribute` yields one item per attributed method with its `MethodModel`, containing `TypeModel`, `SyntaxInfo` and attributes.

## Touches
- `src/Haitch.Roslyn/Generators/SyntaxValueProviderExtensions.cs`
- `tests/Haitch.Roslyn.Tests/Generators/MemberDiscoveryTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including: instance, static, generic and nested-type methods; a partial method attributed on one part yields one item; a local function and a lambda with the attribute yield nothing; the tracking name appears in run steps; and `AssertCacheable` passes for the step.

## Constraints
- Signature mirrors `ForTypesWithAttribute`: `(this SyntaxValueProvider, string fullyQualifiedMetadataName, string trackingName)` returning `IncrementalValuesProvider<(MethodModel Method, TypeModel ContainingType, SyntaxInfo Syntax, EquatableArray<AttributeModel> Attributes)>`.
- Predicate is `node is MethodDeclarationSyntax`. The containing type is `TypeModel.From(containingType, includeMembers: false, ct)`; pass the token to every `From` that takes one.
- Partial methods: one item per symbol (definition part), attributes from the symbol, dedupe like `ForTypesWithAttribute` does for partial types.
- Shipped-source rules: explicit usings, no implicit usings.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Properties, fields, custom predicates, constructors, operators, local functions.
