# 31.3 Trim the harness convenience overloads

## Goal
`GeneratorHarness` has exactly four entry points: `Run(generator, GeneratorHarnessInput)`, `Run(generator, params string[] sources)`, `AssertCacheable(generator, GeneratorHarnessInput, steps, CacheabilityOptions? options = null)`, and `AssertCacheable(generator, IEnumerable<string> sources, params string[] trackedStepNames)`.

## Touches
- `src/Haitch.Roslyn.Testing/GeneratorHarness.cs`
- Every caller the compiler flags in `tests/` and `samples/`. This is a mechanical, compiler-driven change and is exempt from the five-file rule, as 22.1 was. List each file in the report.
- `src/Haitch.Roslyn.Testing/README.md` (or wherever the testing package's readme lives) and the repo `README.md`, only if they show a removed overload.

## Acceptance
`.claude/check.sh` exits 0, and:
- `grep -nE "additionalReferences|CSharpParseOptions\? parseOptions" src/Haitch.Roslyn.Testing/GeneratorHarness.cs` finds no public-method parameters;
- `grep -c "public static GeneratorHarnessResult" src/Haitch.Roslyn.Testing/GeneratorHarness.cs` prints 4.

## Constraints
- Delete these:
  - `Run(generator, IEnumerable<string>, refs?, parseOptions?)`;
  - `AssertCacheable(generator, sources, steps, refs?, parseOptions?)`;
  - `AssertCacheable(generator, sources, steps, CacheabilityOptions, refs?, parseOptions?)`.
- Add `Run(generator, params string[] sources)` delegating to the input overload. Keep `AssertCacheable(generator, sources, params string[] trackedStepNames)` delegating to the input overload directly.
- Callers that passed references, parse options or `CacheabilityOptions` move to `GeneratorHarnessInput`. Callers that passed a sources collection to `Run` pass it as an array or spread (`[.. list]`). Do not change what any test asserts.
- Delete tests whose only purpose was proving that a removed overload delegates, and list them. Keep any scenario they covered that the remaining overloads still need.
- Update the XML docs, keeping the "new options provider" sentence.
- Red/green here: the Acceptance count prints 6 before and 4 after; show both. Edit only with Rider MCP tools.

## Out of scope
- Renaming or changing `GeneratorHarnessInput` or `CacheabilityOptions`.
- haitch-web docs, which are updated at release.
