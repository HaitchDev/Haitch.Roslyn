# 3.5 SyntaxInfo

## Goal
`SyntaxInfo` captures syntax-only facts about a type declaration as value-equal data: whether it and every containing type are `partial`, and its `LocationInfo`.

## Touches
- `src/Haitch.Roslyn/Models/SyntaxInfo.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/SyntaxInfoTests.cs` (new)

## Acceptance
Rider test run of `SyntaxInfoTests` passes, covering: partial top-level type, non-partial type, partial nested in non-partial, location of the identifier, and equality across two parses.

## Out of scope
- Diagnostics for non-partial types (consumers decide).
