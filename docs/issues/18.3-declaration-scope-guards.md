# 18.3 Declaration scope guards

## Goal
`FileScope`, `NamespaceScope`, `TypeScope` and `PropertyScope` throw `InvalidOperationException` when written to while one of their child scopes is still open; disposing one with a child open closes the child and records no error (Dispose never throws).

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/FileScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/NamespaceScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/PropertyScope.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/ScopeGuardTests.cs`

## Acceptance
`dotnet test` from the repo root passes, including `ScopeGuardTests` for: a member written to a type while a method body is open; a type added to a namespace while another type is open; `Using` on a file while a namespace is open; a property accessor added while another accessor body is open; a copied scope disposed twice.
