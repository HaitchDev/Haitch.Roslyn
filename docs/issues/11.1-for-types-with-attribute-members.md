# 11.1 ForTypesWithAttribute can include members

## Goal
`ForTypesWithAttribute` called with `includeMembers: true` yields a `TypeModel` whose `Fields`, `Properties` and `Methods` hold the marked type's declared members.

## Touches
- `src/Haitch.Roslyn/Generators/SyntaxValueProviderExtensions.cs` (add `bool includeMembers = false` after `trackingName`; pass it to `TypeModel.From`)
- `tests/Haitch.Roslyn.Tests/Generators/SyntaxValueProviderExtensionsTests.cs` (and its test generators in the same file, if they live there)

## Acceptance
`dotnet test` from the repo root passes the full suite, including new tests `Should_include_members_of_every_part_when_requested` (a type marked on one part with a field in a second part yields one item whose `Fields`, `Properties` and `Methods` are asserted by name), `Should_leave_members_empty_by_default`, and `Should_stay_cacheable_with_members_included` (`GeneratorHarness.AssertCacheable` over a generator that passes `includeMembers: true`).

## Constraints
- Opt-in: the default stays `false`, and every existing caller and test is unchanged. The existing parameter order stays, so the change is source-compatible.
- The transform lambda may no longer be `static` once it captures the flag; keep it allocation-free per item beyond what `TypeModel.From` already does. Two `Select`-free variants (one per flag value) are also fine.
- The model stays value-equal: no symbols, syntax or locations enter it. Members come from the symbol (`GetMembers()`), so every partial part contributes; keep `TypeModel.From`'s existing member filters (no indexers, no implicit members).
- Document on the method that member capture ties the item's equality to every member edit, so an edit to any member of the type recomputes downstream steps.
- TDD: show the members test failing (empty `Fields`) before the change.
- Edit only with Rider MCP tools; never write files via Bash.

## Out of scope
- Changing `TypeModel.From` or the member models (the `IsSealed` interface quirk and `MethodModel.From`'s missing `CancellationToken` stay as documented).
- Capturing nested types or events.
- The sample generator (11.2).
- Notes: prerequisites 3.4 and 7.2. Raised in the handoff's known limitations.
