# 10.3 Method and body scopes

## Goal
`TypeScope.Method(MethodModel)` opens a body scope that writes the method signature with a braced body, exposing only `Line(...)` and nested `Block(header)`.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/BodyScope.cs` (new)
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs` (split signature rendering from its `;` terminator; no behaviour change)
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/MethodScopeTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `MethodScopeTests`: a generic method with constraints renders the same signature as `WriteMethodSignature` minus `;`, followed by a body with lines and a nested `Block("if (x)")`; `ScopeCompileCheck` reports CS1061 for `body.Method(...)` and for `ns.Method(...)`; existing `SourceWriterExtensionsTests` still pass unchanged.

## Out of scope
- if/for/switch/try builders; expression-bodied members; local functions.
- Properties and fields (10.4, 10.5).
- Notes: prerequisites: 10.2. `BodyScope.Line(string)` returns the same scope for chaining; `Block(string header)` writes the header line then returns a nested `BodyScope` whose `Dispose` closes the brace. Abstract or interface methods still use `WriteMethodSignature`; `Method` on such a model throws `ArgumentException` (a body is illegal there).
