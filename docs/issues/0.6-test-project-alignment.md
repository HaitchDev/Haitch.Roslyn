# 0.6 Test project alignment

## Goal
The tests compile the package sources against the same Roslyn version the package targets, and `PackageSurfaceTests` also covers global-namespace types.

## Touches
- `tests/Haitch.Roslyn.Tests/Haitch.Roslyn.Tests.csproj`
- `tests/Haitch.Roslyn.Tests/PackageSurfaceTests.cs`

## Acceptance
`dotnet build` has zero warnings and `dotnet test` passes; `PackageSurfaceTests` is red when a public type is temporarily added to a src file in the global namespace, and green after it is removed.

## Out of scope
- Any src change.
- Notes: set the test project's `Microsoft.CodeAnalysis.CSharp` to 4.8.0 so a newer Roslyn API in src cannot compile in tests while failing for consumers. Add `Link="Src\%(RecursiveDir)%(Filename)%(Extension)"` to the src Compile include. Global-namespace types to check are those declared in files under `src` (e.g. exclude TUnit/Polyfill-generated types by excluding namespaces `System*`, `Polyfills`, `TUnit*`, `Microsoft*`).
