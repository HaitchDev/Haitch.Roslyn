# 10.1 File and namespace scopes

## Goal
`writer.File()` returns a `ref struct` file scope whose `Namespace(name)` opens a disposable namespace scope that cannot nest another namespace.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/FileScope.cs` (new)
- `src/Haitch.Roslyn/Writing/Scopes/NamespaceScope.cs` (new)
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/ScopeCompileCheck.cs` (new; test helper)
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/FileAndNamespaceScopeTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `FileAndNamespaceScopeTests`: `using var file = writer.File(); using (file.Namespace("A.B")) { }` renders the auto-generated header, `namespace A.B` with a block, then closes it; `ScopeCompileCheck` compiles a legal snippet with no errors and an illegal one (`file.Namespace("A").Namespace("B")`) with error CS1061.

## Out of scope
- Type, member and body scopes (10.2 to 10.5).
- File-scoped `namespace X;` (it cannot be closed by `Dispose`), `#if` regions, `using` directives beyond `FileScope.Using(string)`.
- Notes: prerequisites: none (slice 4 is done). `File()` is an extension method declared in `FileScope.cs`, so `SourceWriter.cs` stays untouched. Design assumptions for the whole slice (human to correct here): (1) layered on the existing `SourceWriter` and `SourceWriterExtensions`; their API stays and keeps working; (2) every scope is an `internal ref struct` with a public `Dispose()` so it works with `using` and cannot be stored, boxed or captured; (3) hierarchy file → namespace → type → method/property/field → body, and each scope exposes only the children legal at that position, so illegal nesting fails to compile; (4) bodies are raw `Line(...)` plus a generic `Block(header)`; no if/for/switch builders; (5) modifier and signature rendering is reused from `SourceWriterExtensions`, never duplicated; (6) tests check both rendered text and, through `ScopeCompileCheck`, that illegal nesting is a compile error. Known limitation (accepted): a parent scope stays usable while a child is open, and copying a scope then disposing both closes twice; document this on `FileScope`. `File()` writes `WriteAutoGeneratedHeader` and `#nullable enable`. `ScopeCompileCheck` compiles the snippet together with `src/Haitch.Roslyn/{Writing,Models,Types}/**/*.cs` read from `RepoPaths.Root`, with `LanguageVersion.Latest` and net10 trusted-platform references, and returns error ids; do not reuse `CompilationHelper`'s C# 12 pin if it blocks `ref struct` usage.
