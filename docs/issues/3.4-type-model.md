# 3.4 TypeModel

## Goal
`TypeModel` captures an `INamedTypeSymbol` declaration as value-equal data: namespace, name, kind, accessibility, modifiers, type parameters, containing types, attributes and member models.

## Touches
- `src/Haitch.Roslyn/Models/TypeModel.cs` (new)
- `src/Haitch.Roslyn/Models/ContainingTypeModel.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/TypeModelTests.cs` (new)

## Acceptance
Rider test run of `TypeModelTests` passes, covering: class/struct/record/record struct/interface, global namespace, nested types with containing chain, generic constraints, static/abstract/sealed, and equality across two compilations of the same source.

## Out of scope
- Syntax facts such as `partial` (3.5).
