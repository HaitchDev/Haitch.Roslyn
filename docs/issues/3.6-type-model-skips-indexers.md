# 3.6 TypeModel skips indexers

## Goal
`TypeModel.From(includeMembers: true)` builds a model for a type that declares an indexer, without throwing.

## Touches
- `src/Haitch.Roslyn/Models/TypeModel.cs`
- `tests/Haitch.Roslyn.Tests/Models/TypeModelTests.cs` (or the existing test file that covers `TypeModel.From`)
- `README.md` (the Notes line about `includeMembers`, if it needs a word on indexers)

## Acceptance
`dotnet test` from the repo root passes the full suite, including a new test that builds a model with `includeMembers: true` from a type with an indexer plus a normal property, and asserts the property is captured and the indexer is not.

## Constraints
- Skip indexers when collecting properties. `PropertyModel.From` keeps rejecting indexers, so a direct call still fails loudly.
