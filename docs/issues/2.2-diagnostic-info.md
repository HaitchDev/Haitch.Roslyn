# 2.2 DiagnosticInfo

## Goal
`DiagnosticInfo` captures a descriptor, optional `LocationInfo` and message arguments as value-equal data and creates the equivalent Roslyn `Diagnostic`.

## Touches
- `src/Haitch.Roslyn/Diagnostics/DiagnosticInfo.cs` (new)
- `tests/Haitch.Roslyn.Tests/Diagnostics/DiagnosticInfoTests.cs` (new)

## Acceptance
Rider test run of `DiagnosticInfoTests` passes, covering: equality for same descriptor/location/args, inequality when any differs, `ToDiagnostic()` producing the right id, severity, location and formatted message, and creation with no location.

## Out of scope
- Result types (2.3).
- Notes: message arguments are stored as `EquatableArray<string>`; `DiagnosticDescriptor` is itself equatable and safe to hold.
