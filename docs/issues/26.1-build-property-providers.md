# 26.1 Build-property providers

## Goal
`ForBuildProperty(name)` and `ForBuildProperties(names)` expose MSBuild build properties as cacheable values.

## Touches
- `src/Haitch.Roslyn/Generators/AnalyzerConfigOptionsProviderExtensions.cs` (new)
- `src/Haitch.Roslyn/Models/BuildProperties.cs` (new)
- `tests/Haitch.Roslyn.Tests/Generators/BuildPropertyTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including (via `GeneratorHarnessInput.GlobalOptions`): a set property; a missing property is null; an empty or whitespace property is null; several properties read at once with `TryGet`; changing an unrelated source keeps the step cached (`AssertCacheable`).

## Constraints
- Extensions on `IncrementalValueProvider<AnalyzerConfigOptionsProvider>`: `ForBuildProperty(string name)` returns `IncrementalValueProvider<string?>`; `ForBuildProperties(params string[] names)` returns `IncrementalValueProvider<BuildProperties>`.
- `BuildProperties` is an equatable record over an `EquatableArray` of name/value pairs with `TryGet(string name, out string? value)` and an indexer returning null for unknown names.
- Reads `build_property.<Name>` from `GlobalOptions`. XML docs name `CompilerVisibleProperty`.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Per-file options, additional files, typed parsing (bool/int) of property values.
