# 4.2 Typed writer helpers

## Goal
`SourceWriter` extensions write an auto-generated header, a namespace, a type declaration wrapped in its containing types, and member signatures directly from the slice 3 models.

## Touches
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs` (new)
- `tests/Haitch.Roslyn.Tests/Writing/SourceWriterExtensionsTests.cs` (new)

## Acceptance
Rider test run of `SourceWriterExtensionsTests` passes, covering: header with `// <auto-generated/>` and `#nullable enable`, file-scoped and global namespace, a partial declaration nested two levels deep, a generic type with constraints, and a method signature from a `MethodModel`; each asserted against a raw string literal and compiled without errors alongside the original source.

## Out of scope
- Method bodies or expression builders.
