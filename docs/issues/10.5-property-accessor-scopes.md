# 10.5 Property accessor scopes

## Goal
`TypeScope.Property(PropertyModel)` opens a property scope whose accessor methods (`Get`, `Set`, `Init`) each open a body scope.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/PropertyScope.cs` (new)
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/PropertyScopeTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `PropertyScopeTests`: a property with a `get` body and a `private set` body renders and compiles with Roslyn; `ScopeCompileCheck` reports CS1061 for `property.Line(...)` and `property.Method(...)`.

## Out of scope
- Expression-bodied accessors, `field` keyword helpers, indexers, events.
- Notes: prerequisites: 10.4 (reuses its property header rendering and `TypeScope.cs`). Accessor accessibility comes from the model's `PropertyAccessorModel` matching that kind, written only when it differs from the property's; asking for an accessor the model does not have throws `ArgumentException`.
