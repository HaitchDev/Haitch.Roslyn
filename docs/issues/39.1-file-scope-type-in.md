# 39.1 FileScope writes a type inside its own namespace

## Goal
`FileScope.TypeIn(TypeModel type)` declares `type` inside `type.Namespace`'s block when it has one and at file level when it is in the global namespace, so a generator writes either case with one call instead of branching.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/FileScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs` (only if disposal must also close the namespace block)
- `tests/Haitch.Roslyn.Tests/Writing/` (the existing FileScope test file)

## Acceptance
`.claude/check.sh` exits 0, including the new `TypeIn` tests.

## Constraints
- Signature: `public TypeScope TypeIn(TypeModel type, EquatableArray<TypeRef> baseTypes = default)`. Output for a namespaced type is exactly what `Namespace(type.Namespace)` then `.Type(type, baseTypes)` writes today; for a global-namespace type exactly what `Type(type, baseTypes)` writes. Disposing the returned scope closes every block it opened (the namespace too). Test both cases, plus a containing type inside a namespace.
- Same guards and exceptions as `Type` (file-local types, pending attributes); share the existing path, do not duplicate it.
- XML doc comments in the style of `Type`, saying when the namespace block is written.
- TDD in tiny steps, one hat at a time: each behaviour step starts from a test seen failing for the right reason, then the minimum code to pass; refactors are separate steps with tests green, at least one per behaviour cycle (prep before the red test where a reshape makes the feat trivial, cleanup after). A later test that passes on first run means the earlier `feat:` overshot; avoid that.
- Commit every step: the failing test alone as `test: ...`, then `feat: ...` only when it turns that test green, and each refactor as its own `refactor: ...`. Lowercase conventional subject only, no body, no trailers. Stage paths explicitly. Commit this issue file first as `docs: add issue 39.1 file scope type in`.
- Rider MCP is not available to this worker: edit with Edit/Write (not `sed -i`), build and test with the dotnet CLI, format with `dotnet csharpier format` on touched files.
- `src/` compiles against Roslyn 4.12. Shipped types stay `internal`.
