# 27.3 TypeScope.Event

## Goal
`TypeScope.Event(EventModel)` writes a field-like event declaration as a member, with buffered attributes and member spacing.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs`
- `tests/Haitch.Roslyn.Tests/Writing/TypeScopeEventTests.cs` (new)

## Acceptance
`.claude/check.sh` exits 0, including tests where generated output compiles under `#nullable enable` for: a public instance event with `EventHandler?`; a static event; a `PropertyChangedEventHandler?` event implementing `INotifyPropertyChanged` on a partial class; an attribute buffered with `Attribute()` before the event; blank-line separation between an event and the next member; and rejection (throws) of a model that is not field-like or is an explicit implementation.

## Constraints
- Renders `[accessibility ][static ][modifiers ]event <Type> <Name>;` from the model's flags, the same way `Field`/`AutoProperty` render theirs.
- Goes through `BeginMember()`, so attributes and blank lines behave like every other member.
- Accessor-bodied events are rejected; that is the documented behaviour.

## Out of scope
- Accessor-bodied events.
