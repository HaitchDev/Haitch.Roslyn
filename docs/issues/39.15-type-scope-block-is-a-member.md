# 39.15 TypeScope.Block is written as a member

## Goal
`TypeScope.Block(header)` begins a member exactly as `Method(...)` does: a blank line separates it from an earlier member, and attributes buffered with `TypeScope.Attribute(...)` are written above its header.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- the `TypeScope` writer test file 39.14 used
