# 4.1 SourceWriter

## Goal
`SourceWriter` produces correctly indented source text with lines, blank lines, and `using` block scopes that open and close braces.

## Touches
- `src/Haitch.Roslyn/Writing/SourceWriter.cs` (new)
- `tests/Haitch.Roslyn.Tests/Writing/SourceWriterTests.cs` (new)

## Acceptance
Rider test run of `SourceWriterTests` passes, covering: nested blocks, multi-line text re-indented, blank lines not indented, custom block delimiters (e.g. `{`/`};`), `\n` line endings, and a `ToSourceText()` conversion with UTF-8 encoding. Expected output is written as raw string literals.

## Out of scope
- Typed helpers (4.2).
- Snapshot libraries.
