# 3.2 AttributeModel

## Goal
`AttributeModel` captures an `AttributeData` as value-equal data: attribute type, constructor arguments and named arguments as typed constants.

## Touches
- `src/Haitch.Roslyn/Models/AttributeModel.cs` (new)
- `src/Haitch.Roslyn/Models/ConstantValue.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/AttributeModelTests.cs` (new)

## Acceptance
Rider test run of `AttributeModelTests` passes, covering: no arguments, primitive/string/enum/`typeof`/array arguments, named arguments, null values, and equality across two compilations.

## Out of scope
- Member and type models (3.3, 3.4).
