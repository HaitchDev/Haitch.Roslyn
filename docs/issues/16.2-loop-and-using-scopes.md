# 16.2 Loop and using statement scopes

## Goal
`BodyScope.ForEach`, `For`, `While` and `Using` each write their statement header and return a `BodyScope` for its block.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/BodyScope.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/StatementScopeTests.cs`

## Acceptance
`dotnet test` from the repo root passes the full suite, including new tests asserting the full output of `ForEach("var", "item", "items")` → `foreach (var item in items)`, `For("var i = 0", "i < n", "i++")`, `While("x > 0")`, `Using("var stream = Open()")`, a loop nested in a loop, and a test compiling all of them inside one method with zero errors; blank-argument rejection with the writer untouched (`For` allows empty initializer/condition/iterator, rendering `for (;;)`).

## Constraints
- Each method validates before writing, then writes the header and opens a block, like `Block(header)`.
- `ForEach` takes `(string type, string identifier, string collection)`; `await foreach` and `await using` are out.
- If 16.1 has landed, add the same methods to `IfScope` only by delegation (no duplicated rendering); otherwise leave it.
- Existing output stays byte-identical.
- TDD: show the first test failing (CS1061) before the code.
- Edit only with Rider MCP tools; never write files via Bash.

## Out of scope
- `do`/`while`, `lock`, `fixed`, `checked`, async forms, using declarations (`using var x = ...;` is a plain `Line`).
- Notes: prerequisite 10.3; runs after 16.1 (same files).
