# 39.7 A constant value is built from a symbol's value and rendered as a C# literal

## Goal
`ConstantValue.From(object? value, ITypeSymbol type)` builds the model for a compile-time constant read from an operation, field or parameter (null, primitives, strings, enums), and `constantValue.ToLiteral()` returns its C# literal text (the text the writer already renders), so a generator turns a rule argument into literal source without `SymbolDisplay` calls of its own.
