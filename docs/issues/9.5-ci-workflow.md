# 9.5 CI workflow

## Goal
`.github/workflows/ci.yml` runs build, test, pack on every push to `main` or pull request.

## Touches
- `.github/workflows/ci.yml` (new)

## Acceptance
`actionlint .github/workflows/ci.yml` exits 0, and the workflow's commands run locally in order (`dotnet restore && dotnet build -c Release --no-restore && dotnet test -c Release --no-build && dotnet pack -c Release --no-build -o "$TMPDIR/haitch-ci"`) succeed.

## Out of scope
- Publishing, secrets, OIDC permissions, branch protection rules.
- Uploading packages as artifacts beyond `actions/upload-artifact@v4` of the pack folder (optional).
- Notes: NEEDS HUMAN: `actionlint` is not installed (`brew install actionlint`); a human pushes to GitHub to see the first run. Prerequisites: 9.1 (independent of 9.4; same step layout so the two stay comparable). `permissions: contents: read`; SDK via `actions/setup-dotnet@v4` with `global-json-file: global.json`; `ubuntu-latest`. `PackageSmokeTests` and `PackageMetadataTests` shell out to `dotnet pack`, so they must pass on Linux too; flag any path assumptions you notice.
