# 39.8 A type's Nullable<T> underlying type is one call away

## Goal
`type.NullableUnderlying()` on an `ITypeSymbol` returns `T` for `Nullable<T>` (including `T?` written with `?`) and `null` for any other type, so generators stop repeating the `OriginalDefinition.SpecialType == System_Nullable_T` check.
