# 17.6 New closed and union types

## Goal
`NewTypeModel` can emit `closed` classes and records and `union` declarations with a case-type list, and rejects combinations the C# 15 compiler rejects.

## Touches
- `src/Haitch.Roslyn/Models/NewTypeModel.cs`
- `src/Haitch.Roslyn/Writing/SourceWriterExtensions.cs`
- `tests/Haitch.Roslyn.CSharp15.Tests/NewTypeCSharp15Tests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `NewTypeCSharp15Tests`: exact output and zero-diagnostic compile for `public closed record Shape;`, a closed class with a body, `public union Pet(Cat, Dog);`, a `partial union` part without a case list, and a generic `readonly` union; and rejection (ArgumentException, writer untouched) for closed + abstract/sealed/static, closed on struct/interface/union, a non-partial union with an empty case list, and union with base types other than interfaces.

## Constraints
- `IsClosed` (bool) and `UnionCaseTypes` (`EquatableArray<string>`) are `init` properties; union is a new kind value.
- Validation lives in `ValidateNewType` with the existing message style. Evidence for the rules: CS0106, CS9381, CS9384, CS1031 (prototype against SDK 11 RC1).
- Existing new-type output stays byte-identical.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Union members (fields/auto-properties are illegal in unions; no special validation), primary constructors (19.2).
- Notes: prerequisites 17.1, 17.3.
