# 3.1 TypeRef

## Goal
`TypeRef` captures an `ITypeSymbol` reference as value-equal data: fully qualified name with `global::`, nullability, special type, and whether it is a value type.

## Touches
- `src/Haitch.Roslyn/Models/TypeRef.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/TypeRefTests.cs` (new)
- `tests/Haitch.Roslyn.Tests/Models/CompilationHelper.cs` (new, test-only helper to compile source and get symbols)

## Acceptance
Rider test run of `TypeRefTests` passes, covering: primitives, generic types, arrays, nested types, nullable reference and `Nullable<T>`, type parameters, and equality of captures from two separate compilations of the same source.

## Out of scope
- Members, attributes, declarations (3.2–3.4).
