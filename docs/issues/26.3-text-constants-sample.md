# 26.3 Text-constants sample

## Goal
A sample generator turns `*.txt` additional files into string constants in a class in the `RootNamespace` build property's namespace.

## Touches
- `samples/Haitch.Roslyn.Samples/TextConstantsGenerator.cs` (new)
- `samples/Haitch.Roslyn.Samples.Tests/TextConstantsGeneratorTests.cs` (new)
- `samples/Haitch.Roslyn.Samples.Tests/Expected/` (new `.txt` files)

## Acceptance
`.claude/check.sh` exits 0, including: two files become two constants (`AssertSourceFile`, output compiles); a `ConstantName` metadata value overrides the derived name; a missing `RootNamespace` falls back to a fixed namespace; an unreadable file reports one diagnostic; content with quotes and newlines round-trips; `AssertCacheable` passes.

## Constraints
- Uses `ForBuildProperty`, `ForAdditionalFiles` and the scoped writer; constant values are emitted as escaped regular string literals (not raw strings), so output compiles at the C# version the harness uses.
- File-name rule (strip extension, PascalCase, prefix `_` when starting with a digit) is in one small helper with its own tests in the same test file.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Non-`.txt` files, nested classes per folder, shipping a `.props` file for `CompilerVisibleProperty`.
