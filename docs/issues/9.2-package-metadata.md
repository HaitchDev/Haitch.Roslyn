# 9.2 Package metadata

## Goal
`dotnet pack -c Release` produces both packages with shared metadata (icon, README, license), plus a SourceLink-enabled `.snupkg` for Haitch.Roslyn.Testing only.

## Touches
- `src/Directory.Build.props` (new; imports the root one)
- `icon.png` (copied from `../Haitch.Unions/icon.png`)
- `LICENSE.md` (copied from `../Haitch.Unions/LICENSE.md`)
- `src/Haitch.Roslyn.Testing/Haitch.Roslyn.Testing.csproj` (description and package id only)
- `tests/Haitch.Roslyn.Tests/PackageMetadataTests.cs` (new)

## Acceptance
`dotnet test` from the repo root passes, including `PackageMetadataTests`: it packs both projects to a temp folder with `-p:Version=1.2.3`, then asserts each `.nupkg` contains `icon.png` and `README.md`, its `.nuspec` has the authors, MIT license, repository URL `https://github.com/HaitchDev/Haitch.Roslyn` and commit, version `1.2.3`, a `Haitch.Roslyn.Testing.1.2.3.snupkg` exists, and no `Haitch.Roslyn.1.2.3.snupkg` exists.
