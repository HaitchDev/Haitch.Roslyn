# 27.5 Member partial validation

## Goal
`PartialTypeValidation.ValidateContainingTypes` turns a member's `SyntaxInfo` into a `Result<T>` that fails with a "containing type must be partial" diagnostic.

## Touches
- `src/Haitch.Roslyn/Diagnostics/PartialTypeValidation.cs`
- `tests/Haitch.Roslyn.Tests/Diagnostics/PartialTypeValidationTests.cs`

## Acceptance
`.claude/check.sh` exits 0, including tests for: a field, method and property in a partial type succeed; each in a non-partial type fails with one diagnostic at the member's location carrying the given message argument; a member in a partial type nested in a non-partial type fails; and a generator using it reports the diagnostic through the existing `Result` pipeline helpers (asserted with `AssertDiagnostic`).

## Constraints
- `static Result<T> ValidateContainingTypes<T>(T value, SyntaxInfo syntax, DiagnosticDescriptor containingTypeNotPartial, string messageArgument)`; on success the value is returned unchanged. Match `Validate`'s style and its `DiagnosticInfo` construction.
- Existing `Validate` behaviour and tests are unchanged.
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Validating member modifiers (static, readonly), descriptors shipped by the library.
