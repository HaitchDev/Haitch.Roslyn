# 18.6 Buffered attributes

## Goal
`Attribute()` on File/Namespace/Type scopes buffers its line until the next member is accepted, so a rejected member leaves no attribute written, and disposing a scope with an attribute pending makes the writer's `ToString()`/`ToSourceText()` throw `InvalidOperationException`.

## Touches
- `src/Haitch.Roslyn/Writing/Scopes/FileScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/NamespaceScope.cs`
- `src/Haitch.Roslyn/Writing/Scopes/TypeScope.cs`
- `tests/Haitch.Roslyn.Tests/Writing/Scopes/AttributeScopeTests.cs`

## Acceptance
`dotnet test` from the repo root passes, including `AttributeScopeTests`: all existing exact-output tests unchanged; `Attribute()` then a member rejected by validation leaves the writer byte-identical to before `Attribute()`; `Attribute()` then dispose doesn't throw but `ToString()` does; two attributes then a member write both in order.

## Constraints
- Validation happens before the buffered attribute lines flush. Remove the doc remarks this replaces.
- `Dispose` never throws (round rule in 18.1); use the writer's `RecordError` from 18.4.
