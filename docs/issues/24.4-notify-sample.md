# 24.4 Notify sample

## Goal
A `[Notify]` sample generator turns attributed fields on partial classes into properties that raise `PropertyChanged`.

## Touches
- `samples/Haitch.Roslyn.Samples/NotifyGenerator.cs` (new)
- `samples/Haitch.Roslyn.Samples.Tests/NotifyGeneratorTests.cs` (new)
- `samples/Haitch.Roslyn.Samples.Tests/Expected/` (new `.txt` files)

## Acceptance
`.claude/check.sh` exits 0, including: `_title` becomes `Title` and the output compiles (`AssertSourceFile`); the class gains `INotifyPropertyChanged` only if it does not already implement it; a non-partial containing class reports one diagnostic (`AssertDiagnostic`) and emits nothing for it; a test with a syntax error elsewhere in the input (`AllowInputErrors`) still generates; `AssertCacheable` passes.

## Constraints
- Uses `ForFieldsWithAttribute`, the scoped writer, `DiagnosticInfo` and `Result`; the attribute is emitted in post-initialization as an embedded attribute.
- Field-name rule: strip a leading `_` or `m_`, upper-case the first letter; documented in a short header comment.
- No attribute arguments yet (25.3 adds them).
- TDD: behavioural red first. Edit only with Rider MCP tools.

## Out of scope
- Attribute arguments, dependent properties, `OnChanging` hooks.
